Forecasts Grand Theft Auto VI's launch-day Twitch viewers hour by hour from the first hour's count, blending the median launch-day shape of past rolling-midnight console launches with a level regression on the first hour's print.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
